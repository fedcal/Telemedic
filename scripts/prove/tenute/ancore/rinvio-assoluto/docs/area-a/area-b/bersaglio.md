# Esca sintetica di collaudo (nessun dato reale di paziente)

Questo file esiste SOLO per rivelare una mutazione: se il controllo risolvesse per errore il
rinvio assoluto relativamente alla cartella del sorgente invece che alla radice dell'albero,
finirebbe qui invece che nel vero bersaglio (docs/area-b/bersaglio.md), e l'ancora sotto
lo farebbe passare a torto.
