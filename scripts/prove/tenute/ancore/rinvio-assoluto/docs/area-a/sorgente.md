# Documento sorgente sintetico (nessun dato reale di paziente)

Rinvio ASSOLUTO dalla radice della documentazione (non dalla cartella del file sorgente),
verso un'ancora che il titolo del bersaglio non genera. Se la base fosse la cartella del
file sorgente invece della radice dell'albero, «area-b/bersaglio.md» non esisterebbe
affatto a quel percorso, e il controllo lo segnalerebbe come bersaglio inesistente invece
che come ancora inesistente: questa tenuta prova che la risoluzione usa la radice giusta.
